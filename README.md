# SauceDemo Automation Framework

## Project Overview
Automation framework developed for SauceDemo e-commerce application.

## Technology Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Extent Reports
- Git/GitHub

## Framework Design
- Page Object Model (POM)
- Data Driven Testing
- TestNG DataProvider
- Cross Browser Testing

## Features Automated
- Login
- Product Search
- Add Product to Cart
- Checkout
- Order Completion

## Browsers Supported
- Firefox
- Microsoft Edge

## Execution Command
## Reporting

Extent Reports integrated using ITestListener.

Reports are generated after test execution with:
- Test execution status
- PASS/FAIL details
- Test logs
- Screenshots for failed tests
